# 贡献与维护

先阅读 README 的平台边界，再提交具体复现步骤。修改计时逻辑须同时验证主窗口和 Mini；修改鼠标事件须确认菜单关闭不会启动计时。

验证：`pnpm build`、`pnpm check`、`pnpm test`；原生修改额外运行 `pnpm tauri build --bundles app`（macOS）。隔离回归不替代真实桌面验收。

Agent 协作请在工作开始记录 HEAD、未提交文件及负责范围，避免同时修改同一文件。交接仅记录行为变化、检查结果、已知问题与版本；不要提交对话记录、私人路径、凭据、截图中的私人内容或本地安装产物。每次提交先检查 `git diff --cached`。

公开仓库自独立初始提交建立，不继承私人开发历史。极限双窗口同时写入冲突本 MVP 暂不处理。当前源码版本0.1.1；历史0.1.0 review3为旧试用构建。完成边界要验证最后一秒→完成→重新开始，只允许一个文字节点，闪烁中不能残留数字。
