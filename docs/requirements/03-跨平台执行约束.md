# 跨平台执行约束与范围

目标是基于同一 MVP 做平台移植，不是用每个平台重新解释计时产品。此处“建议”是计划口径，“必须”是功能验收底线。

## 共用底线

React UI、共享状态、统计和数据结构尽量复用。原生窗口入口、拖动、双击时长与安装器通过平台适配实现。禁止将极限并发延期扩大成普通操作重复记账的免责。

系统字体可有小差异，用户操作、数字口径、配色、窗口安全区、半透明状态不得擅自改变。DPI/Retina 应使用逻辑尺寸；窗口位于非焦点状态也能悬停和接收预期首击。主面板和Mini并非两套独立计时器。

## Intel Mac

必须交付实际 `x86_64-apple-darwin` 应用，或含 arm64+x86_64 的 Universal 包。`file/lipo` 架构输出和真机结果都要提供；Apple Silicon 下 Rosetta 测试仅为补充，不替代 Intel 实机。

保留 Cmd+,、Dock 恢复、主窗口关闭为隐藏、CmdQ 彻底退出、透明置顶/非焦点悬停、菜单和拖动行为。最小系统版本不能由编译目标默认值推断，填写实际验证过的系统与设备。

构建参考：安装 x86_64 Rust target；Universal 需要两种 target。目标路径/命令以实际工具链为准，记录完整命令。官方：[Tauri CLI](https://v2.tauri.app/reference/cli/)。不要要求朋友关闭全局 Gatekeeper，未签名包的安装限制要如实记录。

## Windows

建议第一版面向 Windows 11 x64；这个建议不等于已声明支持。开发方填写实际设备/OS矩阵；Windows10、ARM64、Linux不自动纳入。若需要增加系统范围，先写明并补测试证据。

必须改平台构建目标，不沿用仅 app/dmg 的 macOS 安装配置。基线 beforeDevCommand 使用 `PORT=5173 pnpm dev` 的 POSIX 写法；Windows 须用平台配置或跨平台环境变量方式处理，并确认 devUrl 与实际端口一致，不能只改安装目标。优先 Windows 本机/CI 构建；安装器可选 NSIS exe 或 MSI，交付时明确选择。WebView2 依赖要有安装/缺失处理与文档，不能出现用户安装成功却白屏而无说明。官方：[前置依赖](https://v2.tauri.app/start/prerequisites/)、[Windows 安装器](https://v2.tauri.app/distribute/windows-installer/)。

原生双击时间必须读取 Windows 设置（例如 GetDoubleClickTime），使用与 Mac 相同的识别原则；当前 macOS 源码非Mac回退500ms并不等于Windows适配完成。[Microsoft API](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getdoubleclicktime)

主窗口关闭仍可隐藏，必须提供可靠恢复和彻底退出入口：建议托盘菜单含“显示主面板”“退出”。如果选择不同入口，要在交接中说明并确保关闭主面板后无需任务管理器/重启就可恢复；这不是新增商业功能，而是补齐 macOS Dock/CmdQ 的平台等效能力。

测试任务栏最小化/恢复、非焦点首击、透明置顶/阴影、右键菜单、拖动释放、Windows 100/125/150/200% 缩放。至少100%和一个非整数缩放实机通过，其余未测如实填。不得残留无关的macOS API路径或把Ctrl+,当浏览器全局行为。

安装器设置开始菜单/桌面入口（选择哪一种需记录），双击能启动；彻底退出关闭两窗口与进程。单实例/第二次启动怎样处理需记录；基线未实现单实例，不能声称已有保障。若通过单实例机制完成Windows恢复，需专项验证第二次启动不重置计时、不新增独立计时真值。

## 版本与交付

产品名 Flowglass，基线 identifier=com.salcmbfmj.flowglass。同平台升级保留应用标识和用户数据路径，除非明确计划迁移；不要求Mac与Windows之间自动搬数据。package/Cargo/Tauri版本统一，架构和构建标记写清楚，不能给不同包都只叫“最新版”。

允许复用0.1.1并添加显式构建标记进行内测；正式发行前统一版本/tag。包名建议 Flowglass_<版本>_<mac-x64或win-x64>_<构建号>。SHA256、源码commit、实际安装包对齐。

每个Agent只交自己范围的独立commit/分支；共享逻辑若不得不改，要列出规则影响并在M芯片基线上回归。禁止复制旧私有仓库Git历史、对话、凭据、私人路径或完整开发日志到新公开库。参考干净仓库与指定commit，不clone旧私有历史后直接公开。

## 可接受差异与需要报告的差异

可接受：原生标题栏/字体/菜单细小平台差异、安装包形态、恢复入口和快捷键的等效实现。必须验证：透明与悬停、点击延迟、DPI、日期轴安全边界、单窗口结算、实际耗时与轮数。

不接受：Mini切换自动开始、暂停时间计入、设置改变当前轮、旧轮重复记录、窗口隐藏后无法找回、页面裁切、安装器架构错误。

基线固有限制仍保留：无声音/通知、极限并发、运行状态下退出/睡眠不自动暂停、墙钟变化、旧历史估算、字体网络请求。更改任何一条须提需求变更；未验证的平台行为不能用文案保证。
