# 状态与统计规则

规范 FG-MVP-1.1。本文件是业务行为真值，平台不得自行改成“只有完整 25 分钟才计轮数”或“Mini 切换即开始”。

## 状态定义

| 状态 | 条件 | 显示 | 是否记日志 |
| --- | --- | --- | --- |
| 待开始 | running=false, started=false, finished=false | 本轮完整时长、直立 | 否 |
| 运行 | running=true | 根据 endAt 计算，流沙运动 | 结束/中断时才记 |
| 暂停 | running=false, started=true, finished=false | 保留剩余，运行时间停止累加 | 暂停本身不记 |
| 完成 | finished=true, remainingMs=0 | 主 00:00，Mini “完成” | 进入完成时一次 |

临界点可能在下一次 500ms 刷新或操作时进入完成；已经过期而尚未刷新，切换/重置也不能多记、超记。菜单开关不是计时状态。专注与休息遵循同一状态机，只是统计归类不同。

## 操作矩阵

| 动作 | 待开始 | 运行 | 暂停 | 完成 |
| --- | --- | --- | --- | --- |
| 主面板当前模式按钮 / Mini 单击 / 菜单开始暂停 | 开始本轮 | 暂停 | 继续剩余 | 创建同模式新轮并开始 |
| 主面板另一模式按钮 | 切换并开始 | 结算旧轮，切换并开始 | 结算旧轮，切换并开始 | 不重复旧日志，切换并开始 |
| Mini 双击 / 不同模式圆点 / 菜单切换 | 切换待开始 | 结算旧轮，切换待开始 | 结算旧轮，切换待开始 | 不重复旧日志，切换待开始 |
| Mini 当前模式圆点 | 无操作 | 无操作 | 无操作 | 无操作 |
| 主面板重置 / 菜单重置 | 重建同模式待开始，不记空轮 | 结算旧轮，同模式待开始 | 结算旧轮，同模式待开始 | 不重复旧日志，同模式待开始 |
| 菜单外点击/双击，菜单项之外 | 只关闭菜单 | 只关闭菜单 | 只关闭菜单 | 只关闭菜单 |
| 打开历史、返回、取消设置、关闭主窗口 | 状态不变 | 状态不变 | 状态不变 | 状态不变 |

所有新轮次采用当时已保存的模式时长；切换/重置清除旧的 finished 和 started。完成后直接单击开始不是“继续 0 秒”，而是新轮。

## 时间算法与例子

本轮保存 durationMs，运行时保存 endAt；暂停时 remainingMs 保存暂停瞬间剩余。运行剩余 = max(0,endAt-now)，暂停剩余 = remainingMs；展示秒数向上取整。实际投入 = clamp(durationMs-当前剩余,0,durationMs)，日志 seconds = 实际毫秒/1000，可以是小数。

“实际投入”仅是计时运行经过的时间，不是识别用户是否在专注。运行中睡眠或退出后时间戳仍流逝；暂停才排除等待。后台调度慢不应累计超出本轮时长。

| 场景 | 结果 |
| --- | --- |
| 25 分钟专注运行 10 分钟，双击切休息 | 专注+1轮/+600秒；休息采用新设置，待开始 |
| 运行 10 分钟，暂停 20 分钟，再重置 | 专注+1轮/+600秒；暂停等待不算 |
| 25 分钟自然走完，再切换/重置 | 仍是+1轮/+1500秒，不增加第二条旧日志 |
| 完全未开始就反复切换/重置 | +0轮/+0秒 |
| 5 分钟休息结束或中断 | 可写休息日志；专注轮数与专注时长都不加 |
| 运行25分钟轮，保存30/10；剩15分钟时暂停/继续 | duration仍25，剩余不变；继续同轮 |
| 该轮重置 | 旧耗时结算，新专注30分钟待开始 |
| 该轮Mini切休息 | 旧耗时结算，新休息10分钟待开始 |

任何有正耗时的专注日志都计一轮，completed=false 的中断同样计数；0 耗时不写。非常短但正耗时可能计一轮，UI 分钟仍显示0，不引入额外“至少1分钟”的门槛。

自然完成记录 completed=true，提前结束 false；过期后切换/重置按完整时长结算 true。finishIfDue 重读状态，完成后调用/切换/重置不重记。日志的两次独立新轮可各自结算，不能用“同一天同模式只允许一条”来去重。

## 设置与草稿

SET-01：开始或恢复一个已有轮次时，以其冻结 durationMs 为准。已开始的暂停轮和完成轮不随设置保存重置。下一次创建新轮采用设置。

SET-02：未开始的待开始状态可即时更新显示时长；这不是改变一个已经投入时间的旧轮。草稿改变不生效，保存才写入设置，关闭/取消/Esc/遮罩外部丢弃草稿。

## 历史显示

事件按 t 的本地日期归类；t 是结算时刻，跨午夜的一轮归结算日，不拆成两个日期。延迟补结算也按补结算日期；不要自行回填 endAt 日期。

每日轮数 = 当日 mode=focus 且 seconds>0 的记录数；每日分钟 = round(当日专注秒数之和/60)。近7天分钟 = 七个每日分钟相加，不是先将七天秒数合计再 round。活跃天数 = 至少有一轮专注的日期数。

该取整规则可能让显示分钟与精确秒数存在差异；验收时以原始日志秒数检查正确性。若未来改变分钟呈现口径，必须记录需求变更，不能在移植中顺便修改。

## 事件隔离

单击等待系统双击时长+余量后才提交；Mac 当前余量50ms。不得复用旧260ms固定值。第二次 click、dblclick 取消待执行单击。

拖动超5px阈值交原生拖动，清理待执行单击；pointerup/leave结束拖动候选。控件内部 pointer/click/dblclick 隔离，不能外层再次切换。

右键打开菜单清理待提交动作；菜单项执行一次后关闭。背景关闭菜单的一整串 click/dblclick 都是关闭手势，不能让第二次点击切模式。当前实现在系统识别时间内短暂抑制后续点击；结束抑制后新单击应恢复正常。不要为了吞掉双击而永久禁用点击。

## 数据契约（基线实现）

| localStorage键 | 数据 | 约束 |
| --- | --- | --- |
| flowglass-settings | focus, break（分钟） | 专注1–120、休息1–60；默认25/5 |
| flowglass-live | mode, running, endAt, remainingMs, durationMs, started, finished, owner | mode=focus/break；时间毫秒；owner仅保留最后操作标记，不是唯一结算窗口 |
| flowglass-log | 事件数组，每条 t, mode, seconds, completed | t为epoch毫秒；seconds可小数；保留最新5000 |
| flowglass-history | 旧日期到轮数的映射 | 旧记录只能按当前专注时长估算；内存迁移持久化未完成验证 |

snapshot派生secondsLeft，不把两窗口各自递减的秒数当第二个真值。状态/日志变化通过storage事件与同窗口事件广播；技术实现可改成统一原生服务，但要保持行为并说明同平台旧数据兼容方案。不要让两个平台Agent各自改字段导致未来无法合并。

## 完成边界显示不变量

在最后一秒、0秒、完成闪动各相位、悬停与移开、菜单打开、重新开始中，计时区都只有一个当前状态标签。不将旧数字作为退场动画与新完成提示交叠。显示修复不增加第二次结算，专注和休息各自结束仍只写一条日志。
