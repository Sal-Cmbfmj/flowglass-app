## 工作分工

| 角色 | 负责 | 不替代 |
| --- | --- | --- |
| 产品负责人 | 安排开发者、决定范围变化、组织朋友试用 | 不以肉眼同步代替统计校验 |
| 需求/验收方 | 冻结规则、审查差异、Review、测试、判断是否可试用 | 不把开发自测当独立验收 |
| Intel 开发者 | x86_64 构建、macOS 真机兼容与安装 | 不只交一个标注 Intel 的 arm64 包 |
| Windows 开发者 | Windows 构建、安装、窗口生命周期与鼠标适配 | 不把 Web 预览当 Windows 应用验收 |

## 约束与变更

共用一套计时/统计规则；平台实现可不同，用户行为不可擅自改变。仅为适配平台增加必要窗口恢复/退出入口，不顺带增加账号、付费、同步、通知等功能。

默认建议使用 `port/macos-intel` 和 `port/windows` 独立分支或独立工作目录；这是执行约定，不表示已创建分支。两方同时改共享文件时先约定负责人，合并前审查差异，不能用覆盖文件解决冲突。

本轮文件由代码核对、用户已确认规则和既有试用反馈组成；所有未实测平台的 CSV 结果预填“未执行”。现有 M 基线 12 组计时及 6 组菜单/完成状态隔离检查于 2026-10-13 重跑通过，但不替代原生安装/鼠标/跨系统测试。

所有例外、范围变化记录在交接模板；需求/验收方确认后再调整文档。完整对话、私人目录、凭据和本地日志不进入公开 Git 仓库。

本次0.1.1只更新完成提示渲染与Mini边界，不改变计时/统计/设置规则。重点补测FG-057至059；若其他Agent已经基于旧基线开发，合入此差异后重测，不要求无理由重做全部工作。
